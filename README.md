# Hangman

A command-line Hangman game written in Java. Guess the hidden word one letter at a time before you run out of lives.

## Features
- Random word from a built-in list
- ASCII gallows drawing that builds with each wrong guess
- 6 lives per round
- Input validation for repeated or invalid letters
- Win and loss scoreboard across rounds

## How to run
1. Install JDK 17 or newer
2. Download `Hangman.java`
3. Run: `java Hangman.java`

## How to play
Type one letter per turn. Correct letters fill in the blanks, and wrong letters cost a life. Fill in the whole word to win.
